# La Bonne Adresse — maquette indépendante

Site vitrine statique pour **La Bonne Adresse**, restaurant à Superdévoluy (Le Dévoluy, 05).

## Vérification et sources

- Activité : l’établissement apparaît sur le plan officiel de la station publié pour l’hiver 2025/26 ; Tripadvisor contient des contributions datées de janvier 2026.
- Sources : [plan officiel des stations](https://www.ledevoluy.com/app/uploads/ledevoluy-tourisme/2025/12/Plans-des-stations-Hiver-25-26-1.pdf), [Tripadvisor](https://www.tripadvisor.fr/Restaurant_Review-g10717361-d7747031-Reviews-La_Bonne_Adresse-Le_Devoluy_Hautes_Alpes_Provence_Alpes_Cote_d_Azur.html), [Travelski](https://www.travelski.com/station-de-ski/superdevoluy/manger/).
- Logo : aucun logo autonome avec licence de réutilisation explicite n’a été identifié. La signature est temporaire, à remplacer par le logo livré/autorisé par la maison.
- Photos : URLs Unsplash sous licence dans le HTML, utilisées comme ambiance non représentative de l’établissement.
